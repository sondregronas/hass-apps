> ⚠️ **Work in progress** — this repository is still being set up.

A collection of unofficial Home Assistant add-ons.

## Add-ons

- **[QDomyos-Zwift](./qdomyos_zwift)** — bridges Bluetooth fitness equipment to Zwift, Peloton, Apple Health, and other
  virtual training platforms via a WebGL web interface.

## Installation

1. Navigate to **Settings → Add-ons → Add-on Store** in Home Assistant.
2. Click **⋮ → Repositories** and add:
   ```
   https://github.com/sondregronas/hass-apps
   ```
3. Find the add-on you want in the store and click **Install**.
